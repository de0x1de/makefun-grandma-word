Entry for the make.fun bounty [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16): the program writes exactly one word — the single word a grandma would text about AI — to `/output/entry.txt`, with no trailing newline. It validates that the text is one word (letters only, no whitespace, within the 30-character gate) and reads the file back to confirm the bytes match.

## Run it

```sh
python3 main.py
```
